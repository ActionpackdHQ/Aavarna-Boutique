# Aavarna Boutique

Custom designer stitching studio site — Chennai. Cinematic Next.js front end (GSAP · Lenis · Framer Motion).

**Positioning:** Customers bring fabric; the studio stitches to measure. Not a ready-made shop.

## Quick start

```bash
npm install
npm run dev
```
